# Lovely Rose Sagaysay Portfolio

## Run it (no installation required)

1. Extract this ZIP to a folder.
2. Double-click **Open Portfolio.bat** (or open `index.html` in your browser).

The portfolio, styling, icons, images, theme toggle, resume download, and certificate viewer are bundled locally. The chatbot uses a small offline FAQ fallback; live AI chat is optional and requires running the included Node server with an API key. Nothing needs to be installed to view and use the portfolio itself.
